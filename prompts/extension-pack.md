# Agent 拓展包

> 公共仓库版本只保存跨项目通用规则；个人偏好、项目上下文、会话记录和本地环境信息请放在私有存储中。

## 维护规则

- 只记录可跨项目复用的稳定经验、工具约束和安全边界。
- 不记录密码、令牌、Cookie、API 密钥、私钥、账号、邮箱、手机号或完整请求头。
- 不记录本机绝对路径、内网地址、内部域名、业务数据、需求内容、Bug 详情或会话标识。
- 需要引用项目时使用通用占位符，例如 `PROJECT_ROOT`、`INTERNAL_SERVICE_URL` 和 `REDACTED`。
- 写入前确认内容经过脱敏，写入后再次扫描敏感字段。

## 记忆写入模式

- 临时排查结论留在当前任务记录中，不自动升级为长期经验。
- 只有稳定、可复用且不含隐私的规则才适合进入拓展包。
- 用户明确要求记录时，保留问题、原因、方案、验证结果和预防措施。
- 发现旧记录包含隐私时，优先删除或改写旧记录，再同步到下游工具。

## 配置安全

- 共享配置只保存结构和占位符，真实值放在被忽略的本地密钥文件中。
- 修改 MCP 或 Skill 后，以共享源目录为准，再运行同步脚本传播到客户端。
- 任何公开仓库发布前，都要检查已跟踪文件、当前工作树和提交历史；`.gitignore` 不能保护已经被 Git 跟踪的文件。
- 发现已公开的凭据时，先轮换或撤销凭据，再清理提交历史。

## 验证习惯

- 将静态扫描、定向测试、运行时验证和浏览器验收分开记录。
- 只把实际执行过的命令和步骤写成已验证；无法执行的检查要标明阻塞原因。
- 变更后回读目标文件或远程引用，确认结果与预期一致。
