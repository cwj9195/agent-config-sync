# 个人任务查询范围

仅在用户查询“我的任务”“我上周做了什么”“我参与过的项目”等个人范围时读取本文件。

## 账号来源

- 以当前 MCP 连接实际认证账号、接口返回的当前用户或用户本轮明确提供的账号为准。
- 不从技能内容、仓库历史、项目名称或任务作者字段反推个人账号。
- 当前账号无法确认时，先说明缺口并询问用户，不猜测账号。

## 项目和执行范围

- 优先使用用户本轮明确提供的项目 ID 或执行 ID。
- 如果部署方提供了本地未提交白名单配置，只使用该配置范围；技能文件不保存具体项目、执行、项目集 ID 或名称。
- 未提供范围且工具只能进行全局查询时，不默认扫描全部项目；应询问范围，或明确报告工具的范围限制。
- 用户明确提供新项目或执行 ID 时，先实时核验归属，再在本轮使用；不得自动永久加入技能白名单。
- 白名单或用户指定范围没有结果时，只能表述为“指定范围内未找到”。

## 查询口径

- “上周”按自然周，周一至周日。
- 日期优先使用 `finishedDate`，缺失时使用 `openedDate`，并标注日期来源。
- 任务归属以当前连接账号对应的 `openedBy`、`finishedBy` 或接口提供的个人过滤结果为准。
- 每个结果必须核对项目、执行、任务 ID、名称、状态、日期和工时。
- 异常响应、错页、错执行和未覆盖范围必须单独说明，不得解释为无数据。

## 输出要求

输出应包含项目、执行、任务 ID、名称、状态、日期、工时，以及接口异常和排除项；项目和执行名称只使用实时接口返回或用户明确提供的内容。
